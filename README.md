### [Backbone (App)](https://github.com/angeLoon77/Backbone-APP) & [API](https://github.com/angeLoon77/Backbone-API)

A workout tracker for Android and desktop that I'm building solo (currently v1.20a). Instead of typing each record by hand, you paste your whole workout as plain text—in the format I already use to log my training—and the app extracts everything automatically.

<br clear="left" />

**What it does**
- Parses free-text workouts (exercises, sets, reps, weights, tags) with a custom regex-based parser.
- Detects personal records (PRs) automatically and keeps them organized per exercise.
- Connects a front-end app (Flet) to a secure **Flask REST API**, storing accounts and PRs in **PostgreSQL** (Neon).
- Runs on mobile and desktop, featuring token-based user authentication and a PT/EN interface.

**What I learned building it**
- Migrating an application from a local SQLite database to a client-server architecture.
- Building and deploying a secure backend API using Flask and Docker (hosted on Render).
- Implementing JWT/token-based authentication for user sessions.
- Designing a robust regex parser to handle numerous edge cases (decimal weights, one-sided reps, failure tags).

*Tech: Python, Flet, Flask, PostgreSQL, Docker, REST APIs, Regex*
